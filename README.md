# LinguaFlow
**Django-приложение для изучения английских слов и грамматики**

## Возможности
- Управление словарем
- Грамматические заметки
- Запоминание новых слов с помощью карточек

## Ссылки
В проекте для создания базы данных использованы материалы сайтов:
- https://tefl-tesol-certificate.com - для слов на карточках
- https://www.eltbase.com/ - для грамматических заметок
